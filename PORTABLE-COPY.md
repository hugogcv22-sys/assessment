# Marketing coordinator proposals — portable source

All project photos and videos are included under public/__l5e/assets-v1. The existing asset references work locally without Lovable's media service. The remaining stock photo is included under public/portable-media.

Install Bun, run `bun install`, then `bun run dev`. For production run `bun run build` and deploy the generated Cloudflare Worker and its static assets on a TanStack Start-compatible host. GitHub stores the source; GitHub Pages alone does not run this server-rendered app.

Upload the extracted source files to your repository, not this ZIP. Avoid overwriting the Lovable-synced branch with this portable copy; use a separate repository or branch for independent hosting.

Google Fonts and the original walkthrough's Tailwind CDN script still require internet access. Instagram and ordering links continue to open their original websites. No account credentials, Git history, dependencies, or generated build output are included.
